XJ VIN Decoder Reference

Difficulty 1/50 hrs$01984-1990, 1991-1995, 1996, 1997-2001

17-character VIN on dash and door jamb. Position 4 = engine, 5-7 = model, 8 = chassis, 10 = year, 11 = plant.

Decoding the XJ VIN. Position 1 (1 = USA, 2 = Canada). Position 2 (J = Jeep). Position 3 (4 = MPV/SUV). Position 4 engine: S = 4.0L HO MPI, M = 4.0L Renix, B = 2.5L 150, R = 2.1L diesel (export). Position 5-7 vehicle/body: J28/J38 = 2-door, J78/J88 = 4-door, Y = SE/Sport/Classic, U = Country, Z = Limited. Position 8 chassis/trim. Position 9 = check digit. Position 10 model year code (very useful): G=1986, H=1987, J=1988, K=1989, L=1990, M=1991, N=1992, P=1993, R=1994, S=1995, T=1996, V=1997, W=1998, X=1999, Y=2000, 1=2001. Position 11 plant: T = Toledo, OH (vast majority of XJ). Positions 12-17 serial number. Example: 1J4FT68S2WL123456 decodes as 1998 4-door 4.0L Cherokee Limited (8 = Limited) built in Toledo. Sticker on driver door jamb has paint code, trim code, axle code (ratio + open/lim slip), and transmission code - useful when ordering parts that vary by gear ratio (D = 3.07, F = 3.55, G = 3.73, K = 4.10).
