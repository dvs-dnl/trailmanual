Rear Cargo Area Speaker Upgrade

Difficulty 1/51–3 hrs$60–2501984-1990, 1991-1995, 1996, 1997-2001

Rear XJ speakers are 6"x9" or 6.5" in the cargo side trim. Replace with Kicker, Polk, or Pioneer for the back row / cargo fill. Bolt-on install — pull rear trim panel.

XJ rear speaker locations:

  • 1984-1996: 6"x9" in lower cargo side panel, behind a plastic grille.
  • 1997-2001: 6.5" in same location on most trims, or 6x9 on premium audio.

Verify by removing the cargo trim panel — the cutout will tell you size. The mounting flange may need a Metra 82-6900 adapter for some aftermarket 6x9s.

Recommendations:

  • Kicker DSC693 6x9 coaxial: ~$100/pair, drop-in, good output for the price.
  • JBL GTO939 6x9: ~$130/pair, 3-way, balanced sound.
  • Polk DB692 6x9: marine-rated, useful since cargo area gets wet from tailgate seal leaks.

Key trick: the rear cargo speakers face inward at the cargo area, so a lot of their output bounces around. They're better suited to providing 'fill' rather than full-range sound. For real bass, add a subwoofer (separate entry). For balance, set the head unit fade slightly toward the front so the rears don't dominate.

Mounting: stock screws + speed nuts often strip; budget $5 for new screws. Seal between speaker basket and cargo trim with foam tape to prevent vibration buzz.

Why it works

  • manageable install
  • cargo trim accessible
  • wet-resistant marine options

Trade-offs

  • facing inward limits fidelity
  • trim screws strip

Tools required

  • trim tool
  • screwdriver
  • crimper
