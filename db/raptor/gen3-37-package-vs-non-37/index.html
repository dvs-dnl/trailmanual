Gen 3 Raptor 37 Package — Is the $7,500 Option Worth It?

Difficulty 1/50.25–0.5 hrs$0–75002021-present
Short answer

The Gen 3 Raptor 37 Package includes 37x12.5R17 BFG KO2s plus the chassis changes that make them fit: a modified rear crossmember for the 37-inch spare, unique coil spring tuning, larger-rod Fox shocks, and taller rear jounce bumpers. It does not change the gears — the 35-inch Gen 3 already runs a 4.10 rear ratio. If you want 37s on a Gen 3 without the package, gearing is not what you're missing; fitment, spare storage and warranty are.

The $7,500 (approximate MSRP) for the 37 Package is straightforward to frame as paying $7,500 for 37-inch tires. That framing is incomplete. The tires are part of the package; the frame, spring, shock and bump-stop changes that let them work are the rest.

What's Actually in the 37 Package

  • 37x12.5R17 BFGoodrich KO2 tires — four of them plus a matching spare (five total)
  • 17x8.5 forged aluminum beadlock-capable wheels — upgraded from the base Gen 3 forged wheels
  • Same 4.10 axle ratio as the 35-inch truck — the package does not change gears
  • Upgraded Brembo front brake calipers and larger rotors — the 37s add unsprung weight, the Brembos restore braking performance
  • Fox Live Valve shocks with larger-rod shafts, unique coil tuning, and taller rear jounce bumpers — recalibrated for the 37s' additional weight

The Gear Ratio Is the Critical Piece

Every Gen 3 Raptor, 35 or 37, runs 4.10 gears. Moving from the 35s to 37s drops the effective ratio to roughly 3.88 (4.10 x 35 / 37), a change the 450 hp EcoBoost and the 10-speed absorb on a stock-weight truck. The regear guide covers when a heavy or towing truck should go further.

What the package does change is fitment. Everything Ford adjusted in the 37 Package (frame crossmember, spring tune, shocks, bump stops, brakes) reflects the fact that 37s are not aesthetics — they change the truck's dynamic character in ways that require engineering responses.

Building the Equivalent After Purchase

If you buy a base Gen 3 and later want 37s, the cost calculation changes:

  • Four 37x12.5R17 BFG KO2s (replacing the stock 315/70R17s): ~$1,600 for tires
  • Brembo brake upgrade (if desired): $1,800–$3,000
  • Fox shock retune for 37s: $400–$800
  • Total post-purchase parts cost: $3,800–$5,400, before solving where a 37-inch spare goes

That is less cash than the $7,500 option, but the factory package is integrated, warrantied, and calibrated by engineers who knew what they were doing. Ford's position is that putting 37s on a truck built for 35s will void the warranty, and the frame and suspension changes that make the package fit are not sold as a kit.

Who Should Skip the 37 Package

  • Anyone planning to run the truck primarily on-road — the 37s add rolling resistance, reduce fuel economy (about 1–2 MPG vs. stock 315/70), and increase highway noise
  • Anyone planning to upgrade to aftermarket suspension and custom gear ratios regardless — if you're building the truck heavily, the factory package becomes a baseline you'll modify anyway
  • Budget-constrained buyers — the $7,500 adds significantly to purchase price. A Gen 3 base with 315/70R17 is still a capable truck

Who Should Get It

  • Anyone planning serious desert or trail use with 37s — the fitment work and warranty coverage alone justify it
  • Anyone who won't be doing significant aftermarket suspension modification — the factory package is properly engineered
  • Anyone who values factory warranty coverage on the drivetrain

Steps

  1. Confirm via window sticker or build sheet whether a specific Gen 3 has the 37 Package
  2. If buying new: run the math on post-purchase upgrade cost vs. factory option price
  3. If buying used with 37 Package: verify it on the order sheet or the Tread Act label on the driver's B-pillar, and check for the Brembo calipers (red, with "Brembo" cast in)
  4. If buying used without 37 Package and planning to add 37s: budget for the fifth tire, spare storage and suspension changes, and know the warranty position

Why it works

  • Factory integration means all components are calibrated together
  • Covered under Ford's factory warranty
  • Five matching tires including spare
  • Significantly cheaper than adding the equivalent aftermarket

Trade-offs

  • $7,500 is real money on top of an already expensive truck
  • Fuel economy drops 1–2 MPG versus stock 315/70
  • Highway noise increases with 37s
  • Resale value benefit is partial — used 37 Package trucks command a premium, but not the full $7,500 option cost

Tools required

  • window sticker / build sheet (verify 37 package)
  • tape measure (tire and clearance check)
