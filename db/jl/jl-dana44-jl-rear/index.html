Jeep Wrangler JL / Axles

Dana 44 AdvanTEK Rear — Locker Options

Difficulty 5/54–8 hrs$700–17002018-2024
Short answer

This guide is for non-Rubicon JLs that have the Dana 44 M220 rear, usually trucks ordered with limited-slip. Most Sport and Sahara trucks have a Dana 35 instead, so check first: the base rear on those trims is the Dana 35 AdvanTEK, which takes different lockers (see the Dana 35 and Dana 44 locker guide). On an M220, Eaton's 14234-1 ELocker is the direct-fit electric answer ($1,100), and ARB's RD245 is the air-actuated alternative if you already run a compressor.

The JL rear axle is a Dana 44 in name only — the housing is the M220 variant, beefier than the front M210 but with its own carrier specs and spline counts. Rubicons come with the OE Tru-Lok electric locker from the factory, and so does the 2024+ Willys. Earlier Willys trucks and Sport or Sahara trucks with this axle usually have a Trac-Lok limited-slip rear, and the stock M220 uses 32-spline shafts. Knowing exactly what you have determines which locker fits.

Eaton's ELocker is the most common upgrade because it's electric, one-wire activation, and doesn't require an air compressor. The 14234-1 fits 32-spline M220 axles on non-Rubicon JL and JT trucks. The 14313-2 is the 35-spline version, so it only belongs on an axle already running 35-spline shafts. The 19977-010 is the performance 4-pinion option for older 30-spline D44s with 3.73 or numerically lower gears — relevant only if you're running an older D44 conversion or stock gears. Get the spline count from your build sheet or, more reliably, by pulling the diff cover and counting splines on the side gears.

ARB Air Lockers are the air-actuated alternative. The RD245 fits 32-spline M220 rears and costs $1,091 plus another $340 for the compressor (CKMA12) if you don't have one. Two locker reasons to choose ARB: you want full-open behavior on the street (ELockers are also open until engaged, so this is a wash), and you want the option to add a front ARB later sharing the same compressor. If you're already running OBA for tires, the ARB compressor is a no-cost adder.

Install is not a beginner job. You're pulling the carrier, swapping in the locker, setting pinion preload, ring gear backlash (0.005–0.008"), and pinion bearing crush (~15 in-lb rolling torque used). If you're not regearing at the same time, you can re-use the existing ring gear if it's not worn — but most shops will tell you to regear during the locker install since the carrier is out anyway. If this is your first gear setup, pay a driveline shop. Bad setup eats a $1,100 locker.

Steps

  1. Confirm axle: M200 Dana 35 vs M220 Dana 44, spline count (32 stock, 35 with upgraded shafts), and current gear ratio (stamped on ring gear or check VIN build sheet).
  2. Drain rear diff fluid. Pull the cover.
  3. Mark and remove the carrier bearing caps. Note shim locations and orientation.
  4. Pry the carrier out. Measure ring-and-pinion backlash before removing anything (note for re-setup).
  5. Press old carrier bearings, install on new locker carrier with same shims to start.
  6. Drop new locker into housing, install bearing caps, torque to spec (55-70 ft-lbs typical).
  7. Re-check backlash (0.005–0.008") and pattern. Adjust shims as needed.
  8. Run actuator wire (ELocker) along axle tube to a frame-mounted switch, or run ARB air line.
  9. Fill diff with 75W-85 or 75W-90 gear oil — Trac-Lok carriers also need friction modifier; locker carriers do not.
  10. Bench-test actuator before reinstalling driveshaft. Verify locker engages and disengages cleanly.

Why it works

  • Eaton ELocker is fully open until engaged — no street manners trade-off
  • One-wire install, no air system needed for ELocker
  • ARB shares compressor with front locker if planning both
  • Massive traction gain on a non-Rubicon JL

Trade-offs

  • $1,100+ for the locker alone, more if regearing
  • Setup is unforgiving — backlash off by 0.002" eats a ring gear
  • Need to know your spline count before ordering — wrong locker = restock fee
  • ARB requires a compressor, more plumbing

Tools required

  • dial indicator
  • bearing press
  • torque wrench
  • case spreader (optional)
  • shop manual
